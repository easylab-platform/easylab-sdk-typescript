# @easylab/client-sdk

Typed EasyLab client SDK for TypeScript over Connect (easylab.v1 + agent.v1
via the easylab gateway). Generated by buf from
[easylab-platform/proto](https://github.com/easylab-platform/proto).

```ts
import { createEasyLabClient } from '@easylab/client-sdk'

const client = createEasyLabClient({ baseUrl: 'https://easylab.example.com', token: '...' })
const { repos } = await client.lab.listRepos({})
```

Consumed as a git dependency:

```json
"dependencies": {
  "@easylab/client-sdk": "github:easylab-platform/easylab-client-sdk-ts#v0.1.0"
}
```
